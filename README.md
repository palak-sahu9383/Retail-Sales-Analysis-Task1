#  Retail Sales Analysis - Task 1

This project contains end-to-end retail sales data analysis performed using Python, SQL, Excel & Power BI.

### Files Included
- `data_cleaning.py` - Python script for cleaning raw data
- `Retail_Analysis_SQL.sql` - SQL queries for business insights
- `Retail_Cleaned_FINAL.xlsx` - Cleaned final dataset
- `Retail_Raw_Dataset.xlsx` - Original raw dataset
- `Retail_Dashboard.pbix` - Interactive Power BI Dashboard
- `Final_Presentation - Retail Analysis.pptx` - Project presentation

### Tools Used
Python | SQL | Microsoft Excel | Power BI | GitHub
